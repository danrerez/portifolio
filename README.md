# Portfólio | Daniel Cardoso Leão

Portfólio pessoal migrado de HTML, CSS e JS para **React** (Vite), atualizado com meus dados profissionais e as stacks do curso de Sistemas de Informação da UMC.

A versão original em HTML/CSS está no histórico do repositório (commit `2cd7600`).

## Rodar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Estrutura

- `src/data.js`: dados do portfólio (perfil, experiência, formação, stacks, projetos e contato)
- `src/components/`: Hero, Frame, Timeline, Stacks (filtro Curso UMC / No trabalho) e BrowserCard
- `src/index.css`: estilos do portfólio original, mais as seções novas

Hospedado na Vercel.
